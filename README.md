# FinGuard

FinGuard is a personal finance management web application built using Flask and Python. It helps users track expenses, manage budgets, visualize spending patterns, and gain AI-assisted financial insights through an interactive dashboard.

## Features

- User authentication
- Expense tracking
- Income and expenditure management
- Goal planner
- Financial insights
- Expense visualization
- Calendar view
- AI chatbot assistance
- Dark/Light theme
- Responsive UI

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000
```
